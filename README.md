# VideoStop

אפליקציית אנדרואיד שעובדת על שירות נגישות (Accessibility Service). כשהיא מזהה על המסך ניסיון לצפות בוידאו, היא מציגה מסך חסימה מעוצב מעל כל המסך ומשהה את השמע ברקע.

## איך זה עובד
- **שירות נגישות** מאזין לשינויי מסך.
- **זיהוי וידאו**: אפליקציות וידאו מוכרות נחסמות מיד, ובשאר האפליקציות נסרק עץ הרכיבים אחר נגני וידאו (`VideoView`, `PlayerView`, כפתורי נגן וכו').
- **מסך חסימה**: חלון `TYPE_ACCESSIBILITY_OVERLAY` – לא דורש הרשאת "הצגה מעל אפליקציות אחרות".

## התקנה
1. הורדה: [דף ההורדה (Releases → latest)](https://github.com/hershaleh/video-stop/releases/tag/latest) → `VideoStop.apk`.
2. התקנת ה-APK בטלפון.
3. פתיחת האפליקציה → "פתיחת הגדרות נגישות" → הפעלת **VideoStop**.
4. באנדרואיד 13+ (התקנה מחוץ לחנות): הגדרות ← אפליקציות ← VideoStop ← ⋮ ← **אפשר הגדרות מוגבלות**.

## בנייה מקומית
```
gradle assembleDebug
```
(נדרש JDK 17 ו-Android SDK 34)

## התאמה
רשימות הזיהוי נמצאות בסוף `VideoBlockService.kt` (`VIDEO_APPS`, `CLASS_HINTS`, `ID_HINTS`, `LABEL_HINTS`).

## מנגנוני הזיהוי
1. **רשימת אפליקציות וידאו** – חסימה מיידית.
2. **סריקת רכיבי המסך** – נגנים, מזהים וכיתובים.
3. **זיהוי תנועה** – צילום מסך כל ~350ms; אזור של 8%+ מהחלון שמשתנה ב-5 מתוך 6 פריימים אחרונים, באותו מקום. בסצנות כהות הסף יורד. גלילה מדכאת את הזיהוי; נגיעה בלי גלילה (למשל סרגל התקדמות) לא.
   - אנדרואיד 11+: צילום דרך שירות הנגישות.
   - אנדרואיד 8–10: דרך MediaProjection (כפתור "הפעלת זיהוי תנועה" באפליקציה; נדרש להפעיל שוב אחרי אתחול).
4. **דפדפנים** – חסימה לפי דומיין מתוך שורת הכתובת (`BLOCKED_DOMAINS`, `BLOCKED_PATHS`).
5. **תמונה בתוך תמונה** – חלון הוידאו הצף מכוסה במקומו.
6. **מסך מפוצל** – כל חלון נבדק בנפרד.

## עוד
- **פטורים מזיהוי תנועה:** מצלמה, שיחות וידאו, ניווט, משחקים (`MOTION_EXEMPT_APPS`).
- **זיכרון חסימות:** דומיין – 10 דקות, אפליקציה – דקה.
- **קוד הגנה (אופציונלי):** מסכי הגדרות והסרה שמציגים את שם האפליקציה דורשים קוד.
- **פטור מחיסכון בסוללה:** כפתור באפליקציה.

הפרמטרים נמצאים בסוף `MotionDetector.kt` ו-`VideoBlockService.kt`. תיאור לחנות: `STORE_LISTING.md`.

## חתימה
האפליקציה נחתמת תמיד במפתח קבוע (`signing/videostop.jks`, מוגדר ב-`app/build.gradle.kts`), כך שכל גרסה חדשה מתעדכנת מעל הקודמת בלי הסרה.
המפתח נמצא בריפו הציבורי בכוונה: מי שיש לו גישה לריפו יכול לבנות APK שיתקבל כעדכון לאפליקציה. אם זה לא רצוי, יש להעביר את המפתח ל-GitHub Secrets ולהחליף אותו (ההחלפה תחייב הסרה והתקנה מחדש).

## קוד הגנה: עדכון, הסרה ושכחתי קוד
- **עדכון והתקנה** של האפליקציה חופשיים ואינם דורשים קוד. רק מסך **ההסרה**, מסכי הגדרות האפליקציה והגדרות הנגישות של VideoStop מוגנים.
- **שכחתי קוד:** בלחיצה על "שכחתי קוד" (במסך הקוד או בדיאלוג באפליקציה) מתחילה המתנה של שעה (`Prefs.RESET_DELAY_MS`), ובסיומה הקוד מוסר. הזנת הקוד הנכון מבטלת את האיפוס הממתין.

## הגנה מפני כיבוי והסרה
| ניסיון | איך זה נחסם |
|---|---|
| כיבוי בהגדרות הנגישות | מסך הקוד מופיע בכל מסך הגדרות שמציג את שם האפליקציה |
| הסרה, השבתה, עצירה, מחיקת נתונים (מידע על האפליקציה) | אותו דבר |
| הסרה מהמסך הראשי / מחנות האפליקציות / ממנהל האפליקציות של היצרן | מסך הקוד במסכי ההסרה ובכל מסך מערכת שמציג את שם האפליקציה יחד עם מילת פעולה (הסר, עצור, השבת...) |
| הסרה בלחיצה ארוכה | המערכת חוסמת הסרה כל עוד "מנהל מכשיר" פעיל; ביטולו מוגן בקוד |
| עדכון והתקנה | חופשיים |

הקוד נדרש בהפעלה הראשונה של האפליקציה, וההגנה פעילה כל עוד הוא קיים. אם הקוד נשכח: "שכחתי קוד" ← המתנה של שעה.

**לא ניתן לחסום מתוך אפליקציה:** מצב בטוח, ADB, איפוס להגדרות יצרן, ומשתמש אחר במכשיר.

### רשימת בדיקה ידנית
1. להגדיר קוד, להפעיל "הגנה מהסרה". 
2. הגדרות ← נגישות ← VideoStop: מסך הקוד חייב להופיע.
3. הגדרות ← אפליקציות ← VideoStop: מסך הקוד חייב להופיע (גם בעצירה / השבתה / הסרה).
4. מסך ראשי: לחיצה ארוכה על האייקון ← הסרה: חסום (מנהל מכשיר פעיל).
5. חנות האפליקציות ← ניהול ← VideoStop: מסך הקוד.
6. עדכון ה-APK מעל הקיים: עובד בלי קוד.

## רשימת אפליקציות
"ניהול אפליקציות" (דורש קוד) מאפשר לבחור מצב:
- **חסימה בכל האפליקציות** (ברירת מחדל).
- **חוץ מהמסומנות** (רשימה לבנה) – אפליקציות מסומנות לא נבדקות ולא נחסמות.
- **רק המסומנות** (רשימה שחורה) – החסימה פועלת רק בהן.

הרשימה חלה על כל מנגנוני הזיהוי (רשימת וידאו, רכיבים, תנועה, דפדפן ותמונה בתוך תמונה). ההגנה מכיבוי והסרה אינה תלויה ברשימה. בדפדפנים הרשימה חלה על הדפדפן כולו, לא על אתר מסוים.
