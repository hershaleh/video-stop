# VideoStop

אפליקציית אנדרואיד שעובדת על שירות נגישות (Accessibility Service). כשהיא מזהה על המסך ניסיון לצפות בוידאו, היא מציגה מסך חסימה מעוצב מעל כל המסך ומשהה את השמע ברקע.

## איך זה עובד
- **שירות נגישות** מאזין לשינויי מסך.
- **זיהוי וידאו**: אפליקציות וידאו מוכרות נחסמות מיד, ובשאר האפליקציות נסרק עץ הרכיבים אחר נגני וידאו (`VideoView`, `PlayerView`, כפתורי נגן וכו').
- **מסך חסימה**: חלון `TYPE_ACCESSIBILITY_OVERLAY` – לא דורש הרשאת "הצגה מעל אפליקציות אחרות".

## התקנה
1. ב-GitHub: **Actions → Build APK → הרצה אחרונה → Artifacts → VideoStop-debug-apk**.
2. התקנת ה-APK בטלפון.
3. פתיחת האפליקציה → "פתיחת הגדרות נגישות" → הפעלת **VideoStop**.
4. באנדרואיד 13+ (התקנה מחוץ לחנות): הגדרות ← אפליקציות ← VideoStop ← ⋮ ← **אפשר הגדרות מוגבלות**.

## בנייה מקומית
```
gradle assembleDebug
```
(נדרש JDK 17 ו-Android SDK 34)

## התאמה
רשימות הזיהוי נמצאות בסוף `VideoBlockService.kt` (`VIDEO_APPS`, `CLASS_HINTS`, `ID_HINTS`, `LABEL_HINTS`).
